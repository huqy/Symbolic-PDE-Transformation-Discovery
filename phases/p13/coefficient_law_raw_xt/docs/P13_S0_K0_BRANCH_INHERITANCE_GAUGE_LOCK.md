# P13-S0-K0 — Branch / inheritance / gauge lock

This stage creates no formal coefficient payload, candidate population, PDE response, or holdout outcome.

It freezes four things only:

1. byte-exact inheritance of the P11 raw AST / validity / pushforward baseline;
2. P11 L3 as the P13 cap envelope, using the same cap-transition merge semantics as P11 (the unchanged global theta-occurrence cap remains 12);
3. the deterministic quotient by common X/T translations and one positive common scale;
4. P13 branch, claim, arm-design, data-role, and no-leakage registries.

The gauge is not optimized per coefficient field. The zero-shot object is the same raw AST, the same theta vector, and the same deterministic canonicalization rule applied to every field.

K0 deliberately does **not** certify numerical execution of derivative-nesting-2 ASTs on a general coefficient family. The legacy P11 evaluator was written for the earlier active regime and uses a fixed Taylor-jet order. Formal P13 search remains fail-closed until S0-K2 implements and qualifies the general coefficient-jet evaluator needed by L3/m=2.
