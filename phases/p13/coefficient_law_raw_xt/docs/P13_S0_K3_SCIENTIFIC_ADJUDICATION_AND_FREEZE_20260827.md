# P13-S0-K3 — Scientific Adjudication and S0 Freeze

## Purpose

K3 is a freeze/adjudication step. It does not search, fit new candidates, open DEVELOPMENT/SEALED payloads, or use S0 calibration candidates as S1 seeds.

K3 answers one question: has S0 established enough response-blind evidence to authorize only `P13-S1-K0` implementation regression?

## Hard S0 evidence required

1. coefficient-family regime/identifiability;
2. L3/m=2 execution semantics;
3. deterministic common-translation/common-scale gauge equivalence;
4. coefficient-aware FULL versus coordinate-only NULL capacity separation;
5. operational F4-conditioned production-fitter qualification;
6. actual-production V2 residual-graft partial-credit qualification;
7. evaluator G33/G65 fidelity/cost tractability;
8. calibration-only causal physical-response benchmark separation;
9. no leakage/data-boundary violation.

Lower-order coefficient diagnostics remain diagnostic only.

## Candidate governance at freeze

No S0 calibration/burn-in object becomes an S1 candidate or seed. K3 freezes mechanism evidence only. S1 must independently generate its formal candidate registry. No objective top-k, percentile rule, target survivor count, response-aware rule, or early Pareto pruning is authorized. Exact mathematical/numerical equivalence quotienting is allowed because it removes duplicate executions rather than scientific members.

## S1 authorization boundary

K3 PASS authorizes only `S1-K0 — formal search implementation regression`.

It does not yet authorize the first formal search rung. `S1-K0` must independently verify exact paired arm initialization, shared-theta family objective, V2 residual-graft implementation, restart/resume and CPU ledgers, and absence of response/DEVELOPMENT reads.

The preregistered first formal rung after S1-K0 PASS remains:

- arms: `NULL-V2`, `FULL-V1`, `FULL-V2`;
- 4 paired seeds;
- 8192 structural proposals per seed per arm;
- equal proposals primary fairness, exact CPU secondary fairness.

No S0 burn-in, capacity, fitter-cohort, or V2-calibration candidate may seed S1.
